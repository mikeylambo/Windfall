# Export Checklist

## Before Export

- [ ] Open the project in Godot.
- [ ] Confirm the project opens without errors.
- [ ] Confirm the main scene is correct.
- [ ] Run `res://scenes/Test/TestArena.tscn`.
- [ ] Confirm PlayerUnit movement works.
- [ ] Confirm PauseMenu opens/closes.
- [ ] Confirm DebugOverlay toggles.
- [ ] Confirm Godot reports `0 error(s)`.
- [ ] Confirm project name and version are correct.
- [ ] Confirm input map actions are correct.
- [ ] Confirm audio/settings behavior.
- [ ] Confirm save/load behavior if used.
- [ ] Confirm credits/settings/pause screens if included.
- [ ] Confirm platform icons/splash screens if needed.
- [ ] Confirm export presets exist.

## Release Checklist

- [ ] Create a backup zip before export.
- [ ] Tag or rename the project version.
- [ ] Test a clean project open.
- [ ] Export a test build.
- [ ] Run the exported build.
- [ ] Test basic controls in exported build.
- [ ] Test quit/restart/pause behavior.
- [ ] Archive the final build.
- [ ] Archive the source project used for export.

## Notes

This checklist is generic. Each game should extend it with platform-specific requirements.
